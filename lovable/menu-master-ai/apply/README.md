# Apply bundles

Two messages that bring the Lovable project from its current state (round 2 plus the
partial round 3+4 edits) to the GitHub state. Send message 1, wait for it to finish,
then send message 2. Each is under Lovable's 100k-character message limit.

Free alternative: connect the Lovable project to GitHub (Settings → GitHub) and copy the
`src/` tree from `lovable/menu-master-ai/src/` into that repository; Lovable syncs it.
